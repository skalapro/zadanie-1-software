Zapis danych w pamieci nieulotnej ESP32
Projekt wykonany w espidf

Opis 
Program umożliwia zarządzanie konfiguracją systemu rakiety zapisaną w pamięci nieulotnej NVS.

Obslugiwane typy danych:
    int
    float
    bool
    string

Dostępne zmienne
    time
    velocity
    engine_check
    rocket_name

Dostępne komendy
    help
    set
    check
    delete
    check_all
    exit

Funkcjonalności
    zapis danych w pamięci nieulotnej NVS
    odczyt danych
    usuwanie danych
    wyświetlanie wszystkich zapisanych zmiennych
    obsluga błędnych komend
    obsługa błędnych wartości
    wartości domyślne zmiennych
